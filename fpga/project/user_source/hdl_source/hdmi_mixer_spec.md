# hdmi_mixer 规格

## 功能

`hdmi_mixer` 在 HDMI 像素时钟域内对视频流进行流水寄存，并按优先级叠加安路 Logo、算法模式、六位帧计数、目标质心十字和颜色标签。帧计数显示格式为 `CNT:000000`，每次检测到 `I_video_user` 帧首脉冲时加一，达到 `999999` 后回到 `000000`。

## 接口

| 端口 | 方向 | 位宽 | 说明 |
|---|---:|---:|---|
| `I_clk` | 输入 | 1 | HDMI 像素时钟 |
| `I_rst_n` | 输入 | 1 | 异步低有效复位 |
| `I_logo_en` | 输入 | 1 | Logo、模式和帧计数 OSD 总开关 |
| `I_mode` | 输入 | 2 | 当前算法模式 |
| `I_det_boxes` | 输入 | 192 | 三色检测框和质心信息 |
| `I_video_vsync` | 输入 | 1 | 输入场同步 |
| `I_video_hsync` | 输入 | 1 | 输入行同步 |
| `I_video_de` | 输入 | 1 | 输入数据有效 |
| `I_video_user` | 输入 | 1 | 帧首脉冲 |
| `I_video_last` | 输入 | 1 | 行末脉冲 |
| `I_debug_status` | 输入 | 4 | 调试状态 |
| `O_video_rd_en` | 输出 | 1 | 视频读使能 |
| `I_video_rd_data` | 输入 | 24 | 输入 RGB888 像素 |
| `O_hdmi_vsync` | 输出 | 1 | 流水后的场同步 |
| `O_hdmi_hsync` | 输出 | 1 | 流水后的行同步 |
| `O_hdmi_de` | 输出 | 1 | 流水后的数据有效 |
| `O_hdmi_data` | 输出 | 24 | 叠加 OSD 后的 RGB888 像素 |

参数 `H_OFFSET`、`V_OFFSET`、`IMG_WIDTH`、`IMG_HEIGHT` 定义视频窗口，`DEBUG_MODE` 选择正常输出或调试图案。

## 时钟、复位与周期行为

- 所有状态均属于 `I_clk` 时钟域，`I_det_boxes` 和 `I_mode` 由顶层负责跨时钟同步。
- `I_rst_n=0` 时清零视频流水寄存器、坐标和帧计数。
- `I_video_user=1` 的每个有效周期代表一个新帧，六位 BCD 计数器加一。
- OSD 开启时，第一行显示“安路”和 `MODE ...`，第二行显示 `CNT:` 及六位计数；OSD 关闭时三者同时隐藏，但内部计数继续。
- 帧计数区域使用与模式文字相同的一级寄存字符解码，避免把坐标判断和字符选择直接接入 HDMI 输出临界路径。

## 边界条件

- 帧计数在 `999999` 后回绕到 `000000`。
- 复位期间输出同步、数据有效和像素数据均为零。
- `I_video_de=0` 时不叠加 OSD。
- 正常模式下 OSD 只覆盖字形命中的像素，其他像素保持视频数据。

## 验证场景

1. 复位后首个显示值为 `CNT:000000`。
2. 连续输入三个 `I_video_user` 脉冲后显示 `CNT:000003`。
3. 从 `999999` 再输入一个帧首脉冲后显示 `CNT:000000`。
4. 拉低 `I_logo_en` 后计数文字隐藏；重新拉高后显示累计值。
5. 四种 `I_mode` 下模式文字与帧计数同时显示且不重叠。

  { "name": "I_rst_n",      "wave": "01......" },
  { "name": "I_video_user", "wave": "00100010" },
  { "name": "frame_count",  "wave": "x.=...=.", "data": ["000001", "000002"] },
  { "name": "OSD",          "wave": "x..=...=", "data": ["CNT:000001", "CNT:000002"] }
] }
