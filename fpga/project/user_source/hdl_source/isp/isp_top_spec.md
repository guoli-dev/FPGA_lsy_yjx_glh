# isp_top 规格

## 功能

`isp_top` 接收四路并行的 Bayer 视频流，依次完成去马赛克、自动白平衡、Gamma、边缘检测、卡通化、三色目标检测和跟踪框叠加，并按帧切换显示模式。

三色目标检测从 Gamma 输出取样，与动漫模式调整前的识别数据源保持一致。

## 接口

| 端口 | 方向 | 位宽 | 说明 |
|---|---:|---:|---|
| `axi4s_video_aclk` | 输入 | 1 | ISP视频时钟 |
| `I_rst_n` | 输入 | 1 | 异步低有效复位 |
| `I_mode` | 输入 | 3 | 显示模式，帧首采样低2位 |
| `I_tlast` | 输入 | 1 | 输入行末标志 |
| `I_tuser` | 输入 | 1 | 输入帧首标志 |
| `I_tdata` | 输入 | 40 | 四像素Bayer数据 |
| `I_tvalid` | 输入 | 1 | 输入数据有效 |
| `I_tdest` | 输入 | 10 | 输入目的标识 |
| `O_tready` | 输入 | 1 | 下游准备信号 |
| `O_tdata` | 输出 | 128 | 四像素RGB输出 |
| `O_tlast` | 输出 | 1 | 输出行末标志 |
| `O_tuser` | 输出 | 1 | 输出帧首标志 |
| `O_tvalid` | 输出 | 1 | 输出数据有效 |
| `I_tready` | 输出 | 1 | 上游准备信号 |
| `O_det_boxes` | 输出 | 192 | 红、绿、蓝目标的框和质心信息 |

## 模式行为

- `0`：原图。
- `1`：Sobel边缘图，阈值80。
- `2`：卡通化；每通道保留高3位（512色），并把Sobel边缘涂黑。Sobel阈值为60，在描边完整度和弱纹理黑点之间折中。
- `3`：原图叠加目标检测框；模式值由帧首锁存，整帧不切换。
- 其他值按低2位进入现有模式选择逻辑。

## 时钟、复位和约束

- 所有ISP数据通路属于 `axi4s_video_aclk` 时钟域。
- `I_rst_n=0` 时清零模式寄存器和流水寄存器。
- 原图支路延迟一拍，与 `edge_detect_96` 输出对齐；模式选择后再寄存一拍以隔离组合路径。
- 卡通量化位数和边缘阈值只改变组合常数，不改变接口、流水延迟、存储器或DSP使用量。
- 色块识别、显示和边缘处理均使用 `gam_tdata/tuser/tvalid`。

## 验证场景

1. 模式1使用阈值80，输出白边黑底。
2. 模式2使用阈值60，边缘像素输出黑色，非边缘像素执行3位量化。
3. 模式在帧内变化时，实际输出模式只在下一次 `I_tuser` 后改变。
4. 原图、边缘图和卡通图的像素与 `tuser/tlast/tvalid` 保持对齐。
5. 色块识别从Gamma输出取样，模式切换不改变检测数据源。
