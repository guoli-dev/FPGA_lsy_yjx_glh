# AE / AWB / Gamma 实时演示说明

本工程基于 `AE60_no_buzzer_submission_20261026_2315` 的独立副本开发；原提交版工程与 bit 保留不动。

原算法切换键（RTL 的 `I_button[0]`）现在依次循环：0 原图、1 边缘、2 卡通、3 跟踪、4 运动、5 AWB 对照、6 Gamma 对照、7 AE 实时数值、再回 0。`I_button[1]` 仍控制 Logo/OSD。以太网 `0x01` 模式命令只接受 0–4，5/6/7 需要按键切换。

- 模式 5 `MODE AWB`：左半屏 640 像素不做 AWB，右半屏 640 像素做原工程 AWB；两侧都继续经过原 Gamma。屏显 `L:OFF R:ON`。用白纸和彩色物体，在暖/冷光源下观察左右色偏。
- 模式 6 `MODE GAMMA`：左右都做原 AWB；左半屏不做 Gamma，右半屏做原 Gamma。屏显 `L:OFF R:ON`。用同时有暗部与亮部的场景观察暗部细节和黑位。
- 模式 7 `MODE AE LIVE`：全屏为原 AWB+Gamma 实时图像，显示 `EXP:xxxx` 和 `GAIN:xxx`（传感器寄存器值、十进制），以固定机位改变照明，观察数值和亮度逐渐调整。单摄像头不能在同一时刻产生真实的 AE 开/关两种曝光，因此该模式不伪装 AE 实时对照分屏。

对照分屏是同一帧的左右空间区域，并非把同一完整场景复制两遍；观察时尽量让白纸或明暗结构横跨屏幕中线。原 0–4 模式的滤波/检测算法参数与帧率设置均未修改。

上板前须确认本工作副本的最终布线 Setup/Hold WNS 均非负，且 bit 的生成时间晚于本次修改；如未通过，继续使用冻结提交版 bit。
