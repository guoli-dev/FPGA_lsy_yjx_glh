## 拍摄前核对

- 新提交 bit 的 AWB/Gamma 分屏、AE 数值显示、延迟显示及所有模式，先逐项上板验证，再拍相应镜头。不能只凭 RTL 或综合通过宣称实拍效果。
- 对“稳定运行、60 fps、低延迟、资源优化”等评分点，只使用可复核的实测或前后对比数据。没有长期运行记录，不要把短视频说成长期稳定性证明；没有基线数据，不要宣称资源占用下降。
- 小车若未联调成功，保留真实串口输出画面，删去 00:00–00:15 与 01:30–01:44 中已实现控制动作的解说。不要用剪辑伪造联动。
- AWB/Gamma 的对照物必须横跨屏幕中线；AE 只能做同机位前后时刻对比。灯光变化应来自现场，不用后期调色伪装算法。
- 全程横屏拍摄，固定相机曝光/快门以减少拍屏频闪；屏幕、开发板和现场操作都要有镜头。后期旁白与真实画面逐句对应，成片不超过 3 分钟。
